Practice Format

A format is how students browse a course's practice questions - Topic-wise, Subject-wise or Year-wise. Create the format here first, then add the actual questions from Upload CSV / Excel or Manual Entry.

Upload CSV / Excel

  1. Create the paper first in Practice Format, then pick it below.
  2. Download a template (Excel has a "How to fill" sheet explaining every column).
  3. Fill your questions - question_id is the number students see; leave it empty and the next number in the paper is used.
  4. Upload. Every row is checked first: any bad row stops the whole import, and questions already in the paper are skipped - so the same sheet can be uploaded again without duplicates.
New to the format? Download a ready-made template with example MCQ, MSQ, NAT and coding questions. The Excel file includes a How to fill sheet explaining every column.

Image Questions

  1. Set the context once - paper, subject, topic, year - then upload one or many question images (each image is one full question with its options, like a scanned paper).
  2. Use Auto-trim / Crop / Hide / Rotate to clean the image, then drag a rectangle over each option's row (A→D advances automatically) and set the correct answer.
  3. Save & Next stores the question with the next number in the paper and loads the next image. Students see a clickable circle in front of each option.
  4. Undo reverses the last crop, hide, rotate or option mark; crop and rotate keep your marked areas in place.

      How to upload questions

      Store questions with an Excel sheet or Manual entry. Use the image options only when a question exists only as a picture.

      Mock test (competitive) - 4 ways
      1. Excel / CSV sheet (recommended) - download the template from the upload window; one row per question. Every row is checked first: if any row has a problem nothing is saved and each problem is listed, so you can fix the file and upload it again without duplicates.
      2. Manual entry - pick the type (MCQ one answer, MSQ letters joined like AC, NAT a number), fill the text and options with the rich editor, set correct marks and negative marks (accepts 1/3).
      3. Image question - one screenshot per question: crop / hide / rotate, drag over each option's row, click the correct option. Undo reverses any step.
      4. Bulk image upload - an Excel sheet (filename, type, answer, marks) plus all images, marked one by one and saved together.
      Sections and deleting
      • Every section of a test is listed with its ID and name when you open the test - click one to go in, or use Switch section.
      • Tick questions (or Select all) and press Delete selected. Every edit and delete asks for approval first.
      Key fields
      • Test Description - the paper: total questions (upload limit), marks, duration, calculator on/off.
      • Section ID / Name - groups questions (e.g. SEC1 / Physics). Pick it from the list; no need to remember it.
      • correct_option - MCQ: b · MSQ: ac · NAT: the number itself.
      Communication (placement) - 2 ways only
      • Create sections first (title, student instruction, duration in seconds) - names SECTION_A/B/… auto-assigned.
      • Manual - the form adapts per type: MCQ options+answer · SPEAK recording time · THINK_SPEAK think + record time · COMPREHENSION listening MCQ (audio URL on the first question only) · WRITING word limit.
      • Excel / CSV (recommended) - the template has a sample row of every type plus marks columns; section names must already exist. If any row has a problem nothing is saved.
      • No image questions for communication - the test window renders each type with its own UI (recorder, timer, editor).
      Writing a coding question
      The order to work in
      1. Add a section and pick its type. The type cannot be changed later.
      2. Pick that section in step 2, then fill the question.
      3. Save. Repeat for the next question.
      Type it or photograph it

      The question, the input format and the example are three separate parts. Each can be typed or uploaded as an image, and you can mix them - for example upload a photo of a printed question but type the example yourself. After choosing an image you can crop it and white-out anything that should not be shown.

      A worked coding example

      Title: Second largest element

      Question: Given n integers, print the second largest distinct value. If it does not exist, print -1.

      Input format: First line: n. Second line: n space-separated integers.

      Example:

      Input:
5
1 2 3 4 5

Output:
4

      Test cases:

      visible   in: "5\n1 2 3 4 5"   out: "4"
hidden    in: "3\n7 7 7"         out: "-1"
hidden    in: "2\n9 1"           out: "1"

      Always add a hidden case that covers the tricky path - here, all-equal values. Without it a candidate can pass by printing a guess.

      A worked SQL example

      Sandbox schema:

      CREATE TABLE employees (id INT, name VARCHAR(50), salary INT);
INSERT INTO employees VALUES (1,'Asha',50000),(2,'Ravi',72000),(3,'Meera',72000);

      Question: List the names of the highest paid employees.

      Solution query:

      SELECT name FROM employees WHERE salary = (SELECT MAX(salary) FROM employees);

      Only tick Row order matters when the question actually asks for an ORDER BY - otherwise a correct answer in a different order is marked wrong.

      A worked Web example

      Question: Build a card with the heading "Hello" inside #app.

      Checks:

      element exists   selector: #app .card
text equals      selector: #app .card h2    expected: Hello

      Write checks against what the page must contain, not how it is built, so a candidate using different markup is not failed unfairly.

      Adjust the image

      Pick a tool, then drag on the image - it is applied when you let go. Crop keeps only what you dragged over. Hide whites it out (use it to remove an answer or a watermark). Undo reverses the last step. Only what you see here gets saved.

      Image Question
      How to use this tool
      1. Upload one or many images - each image is one full question (text, diagrams and options). They queue up and open one by one.
      2. Use Crop to keep only the question area (removes blank margins), Hide to white-out any portion students must not see, then Mark Options: pick a letter and drag over that option's row.
      3. Students see the image with a clickable circle in front of each marked option - no typing needed.
      4. Undo reverses the last crop, hide, rotate or option mark. Crop and rotate keep your marked areas in place.

        Tip: click an option row above to make it the correct answer (the star shows it).

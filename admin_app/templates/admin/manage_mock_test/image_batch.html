    Guidelines

    1. Pick the test, description and section the questions belong to.
    2. Fill the sheet - one row per question with columns: image_filename (must exactly match an image file you upload), question_type (MCQ or MSQ), correct_option (b, or ac for MSQ), correct_marks, negative_marks (number or 1/3), question_level (Easy/Medium/Tough).
    3. Select all images at once and click Load batch - you’ll see “All images matched successfully”.
    4. For each question: the sheet data is pre-filled on the left; on the right drag a rectangle over each option’s row on the image (A, then B, C, D - the letter advances automatically). Use ⬅ ➡ to move between questions; green thumbnails are complete.
    5. Click Save all questions - every completed question uploads and stores in the database; a per-question log shows the result.

    Students see the full image with a clickable circle in front of each marked option - the circle sits in a clean margin, never covering the paper.

    • Test Description - one exam paper: title, total questions, total marks, duration. The question limit is enforced from here.
    • Section - a named group inside the paper (e.g. SEC1 / Physics). Reuse the same Section ID to append questions.
    • question_type - MCQ one correct option; MSQ multiple correct (answer like AC); NAT numeric answer typed by the student.
    • correct_option - MCQ: one letter. MSQ: letters joined. NAT: the number itself.
    • correct_marks / negative_marks - marks awarded / penalty. Negative accepts fractions like 1/3.
    • answer_text / answer_link - optional explanation shown after the test.

    1. Create the description under a PLACEMENT course - loading its questions opens the Communication panel automatically.
    2. Add sections first (Speaking, Grammar, Listening, Writing…): title, instruction shown to the student, and duration in seconds. Names SECTION_A/B/C… are assigned automatically.
    3. Add questions manually or by sheet. The form changes per type:
    • MCQ - options A-D + correct option (grammar/vocabulary).
    • SPEAK - student reads the question text aloud; set recording time (default 45s).
    • THINK_SPEAK - topic speech; set thinking time (30s) + recording time (60s).
    • COMPREHENSION - listening MCQs; put the audio URL on the first question only, leave it empty on the rest (the same clip covers the section).
    • WRITING - email/essay prompt with a word limit.
